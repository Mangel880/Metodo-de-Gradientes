02 · Caso de estudio

Contexto financiero, supuestos y justificación.

Contexto

Una empresa tecnológica necesita planificar la distribución de recursos entre cuatro unidades: infraestructura tecnológica, desarrollo de software, capacitación y seguridad informática. Las unidades presentan necesidades propias y relaciones de dependencia operativa.

El simulador representa esas relaciones mediante una matriz simétrica de ponderaciones. El vector independiente expresa la carga o necesidad financiera modelada. La solución se interpreta como un nivel de asignación recomendado por el modelo, expresado en miles de bolivianos.

Supuestos del modelo

  • Se consideran cuatro unidades y una misma estructura de variables en los tres escenarios.
  • Los coeficientes de la matriz son ponderaciones simuladas y adimensionales.
  • El vector b representa necesidades financieras agregadas, expresadas en unidades compatibles con el modelo.
  • La matriz debe ser simétrica y definida positiva para aplicar GC/GCP.
  • El modelo es una simplificación académica; no reemplaza un presupuesto contable ni una optimización con restricciones.

Unidades y variables

x₂ · DesarrolloSoftware, licencias y herramientas.

03 · Formulación matemática

Sistema Ax = b e interpretación de la matriz.

A · x = b    con A ∈ ℝ⁴ˣ⁴, x = [x₁, x₂, x₃, x₄]ᵀ, b ∈ ℝ⁴

Los elementos diagonales aᵢᵢ representan la ponderación propia de cada unidad. Los elementos fuera de la diagonal aᵢⱼ representan el acoplamiento modelado entre las unidades i y j. La simetría expresa que la relación se considera compartida: aᵢⱼ = aⱼᵢ.

  • Los datos son simulados y no proceden de registros contables reales.
